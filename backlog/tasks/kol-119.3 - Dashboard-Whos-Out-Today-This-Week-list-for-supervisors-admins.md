## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a list widget for supervisors/admins showing employees currently on approved leave, scoped the same way as the Pending Approvals card (supervisor_id for ApproveTeam:Leave/ViewTeam:Leave, org-wide for admin). Query: Leave::where('status', Approved) whose [start_date, end_date] overlaps today (or the current week, whichever reads better once built). Show each employee's avatar/name, leave type, and return date. Links to leaves/calendar. Empty state when nobody is out.

## User stories for manual testing (Gherkin)

Scenario: Supervisor sees a direct report currently on leave
  Given one of my direct reports has an approved leave overlapping today
  When I visit the dashboard
  Then I see their name, leave type, and expected return date in a 'Who's out' list

Scenario: Nobody on my team is out
  Given none of my scoped employees have an approved leave overlapping the period shown
  When I visit the dashboard
  Then the list shows a clear empty state, not a blank or broken card

Scenario: User without team-leave visibility sees no widget
  Given I hold neither ViewTeam:Leave nor the admin equivalent
  When I visit the dashboard
  Then the 'Who's out' widget is not shown

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add a private whosOut(User $user): ?array method to DashboardController, scoped exactly like LeaveController's viewTeam gate: null when the user holds neither ViewTeam:Leave nor hasRole('admin') (Leave has no dedicated admin permission, mirrors the pendingLeaveRequestsCount decision from KOL-119.2); otherwise Leave::where(status, Approved) whose [start_date, end_date] overlaps today, org-wide for admins else supervisor_id-scoped, mapped to {id, user: {id, name, avatar}, type, type_label, return_date (end_date + 1 day)}.
2. Pass 'whosOut' => $this->whosOut($user) from DashboardController::index. null = widget not shown; [] = shown with an explicit empty state; populated = the list.
3. Add a WhosOutCard to resources/js/pages/dashboard.tsx: not rendered when whosOut is null; shows an empty-state message when whosOut is []; otherwise lists each entry with Avatar/AvatarFallback, name, type_label, and return_date (formatted via useTranslations' formatDate), each row/card linking to the leaves calendar (/leaves/calendar).
4. Add WhosOut type to resources/js/types (or inline in dashboard.tsx) and wire DashboardProps.
5. Add lang keys under ui.dashboard.whos_out in lang/en/ui.php and lang/es/ui.php (title + empty state + 'back on :date' label).
6. Add tests/Feature/DashboardWhosOutTest.php: supervisor sees only their team's overlapping approved leave, admin sees org-wide, a leave outside today's range is excluded, pending/rejected leaves are excluded, empty state (permission held, nobody out) returns [], no permission returns null.
7. pint --dirty, sa test --compact, npm run types:check, live browser check of populated/empty/hidden states for a supervisor and an admin.
<!-- SECTION:PLAN:END -->
