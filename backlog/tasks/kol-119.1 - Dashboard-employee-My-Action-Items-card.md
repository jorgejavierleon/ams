## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a card to the employee-facing dashboard listing the employee's own pending self-service actions: mark-correction requests awaiting their review, and documents awaiting their signature. Both counts already exist as shared Inertia props (auth.pendingModificationsCount, auth.pendingSignaturesCount in HandleInertiaRequests.php, already used for sidebar badges) — reuse them directly rather than adding new queries. Each row links to where the action is actually taken (the mark-modification review screen, Mis documentos). Renders next to the existing ClockCard on resources/js/pages/dashboard.tsx.

## User stories for manual testing (Gherkin)

Scenario: Employee has a pending mark-correction to review
  Given I am logged in as an employee with 1 pending mark-modification request
  When I visit the dashboard
  Then I see a 'My Action Items' card showing the pending correction
  And clicking it takes me to the review screen

Scenario: Employee has a document to sign
  Given I am logged in as an employee with 1 document awaiting my signature
  When I visit the dashboard
  Then the card shows the pending signature
  And clicking it takes me to Mis documentos

Scenario: Employee has nothing pending
  Given I have no pending mark-modification reviews and no documents to sign
  When I visit the dashboard
  Then the 'My Action Items' card is not shown
