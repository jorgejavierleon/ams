## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
RoleController (app/Http/Controllers/RoleController.php) currently only exposes index/show/update (permissions-only edit) — there is no way to create a new role, rename one, or delete one. Add a 'New role' flow (name + permission selection) and delete support, gated by the existing Manage:Role permission like the rest of the Roles screen. Deleting a role that is currently assigned to one or more users must warn how many users will lose that role, and proceed to detach it from them on confirmation (force-unassign, not a hard block). Role names must stay unique (existing Spatie roles.name+guard_name constraint).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A user with Manage:Role can create a new role with a name and an initial set of permissions from the Roles screen
- [ ] #2 A user with Manage:Role can rename a role and edit its permissions after creation
- [ ] #3 A user with Manage:Role can delete a role; if the role is currently assigned to any users, a confirmation step shows how many users will lose the role before deletion proceeds
- [ ] #4 Deleting a role removes it and detaches it from every user who held it, without deleting those users or their other roles
- [ ] #5 Creating or renaming a role to a name that already exists shows a validation error instead of a server error
<!-- AC:END -->
