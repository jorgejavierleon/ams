## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Let an organization's Owner transfer ownership to another user in the same organization, and prevent the organization from ever ending up without an owner.

Transfer must be atomic (the old owner reference and new owner reference change together, never leaving a window with zero or two owners) and restricted to the current owner acting on a target user who belongs to the same organization.

Block deleting or deactivating the current owner's account, and block the owner leaving/being removed from the organization, unless ownership has been transferred to someone else first.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Only the current owner can initiate a transfer, and only to another active user in the same organization
- [ ] #2 Transfer is atomic: at no point does the organization have zero or two owners
- [ ] #3 Deleting, deactivating, or removing-from-organization the current owner is rejected with a clear error unless ownership was transferred first
- [ ] #4 Settings UI exposes an ownership transfer action and shows which user is the current Owner
- [ ] #5 Pest tests cover a successful transfer, a rejected transfer to a user outside the organization, and a rejected self-delete/deactivate while still owner
<!-- AC:END -->
