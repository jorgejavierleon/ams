## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Import Menu icon from lucide-react and Sheet/SheetContent/SheetHeader/SheetTitle/SheetDescription/SheetClose/SheetTrigger from @/components/ui/sheet.
2. Add local open state (useState) in Landing component for the mobile sheet.
3. Add a hamburger Button (md:hidden, accessible name via aria-label or sr-only text) next to/before the Ingresar/Contáctanos controls in the header, wired as SheetTrigger.

## Implementation Notes

Added a mobile nav menu to landing.tsx: a Menu-icon ghost Button (md:hidden, aria-label 'Abrir menú de navegación') opens a shadcn Sheet (side=left) containing the same 4 anchor links (Funciones/#funciones, Cómo funciona/#como-funciona, Planes/#planes, Preguntas/#faq) styled for the light sheet background, each closing the sheet onClick.
