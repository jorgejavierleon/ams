## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
users.is_admin is an unused HR/reporting boolean (Employee form "System" tab checkbox) with no role in authorization — it predates the real admin mechanism (Gate::before + Spatie admin role) and now confusingly shares a name with the Owner/admin-role work in this initiative. Remove it entirely: migration dropping the column, User model cast/fillable, EmployeeController (index filter, show/edit/index props, export filters, create, validation rule), EmployeeImportSchema (import/export field), seeders, and the ES/EN "Admin"/"Administrator" checkbox labels. Update affected tests.
<!-- SECTION:DESCRIPTION:END -->
