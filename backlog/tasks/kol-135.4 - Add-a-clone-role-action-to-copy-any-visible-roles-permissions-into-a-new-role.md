## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a 'Clone' action on the Roles screen for any role a user can currently view (admin/employee/supervisor/custom) — not for dt/saas, which stay fully hidden. Cloning creates a new, ordinary (non-system) role pre-populated with the source role's current permissions, named '<Original> (copy)' (deduplicated, e.g. '(copy 2)', if that name is already taken), and the user lands on it able to rename and adjust it immediately like any custom role created via KOL-135.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Cloning a role (system or custom) creates a new role with identical permissions to the source role at the moment of cloning
- [ ] #2 The cloned role defaults to the name '<Original> (copy)', deduplicated if that name already exists
- [ ] #3 The cloned role is always a normal custom role, even when cloned from admin/employee/supervisor, so it can be freely renamed and deleted afterward
- [ ] #4 No clone action is available for dt/saas roles
<!-- AC:END -->
