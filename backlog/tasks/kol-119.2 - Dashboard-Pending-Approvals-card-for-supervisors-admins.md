## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a card for supervisors/admins summarizing what needs their decision: pending leave requests and pending overtime requests, scoped exactly like each request's own queue (org-wide for the relevant Manage/admin permission, supervisor_id-scoped for ApproveTeam:*). auth.pendingOvertimeRequestsCount already exists in HandleInertiaRequests.php and should be reused as-is. A new pendingLeaveRequestsCount must be added to the same middleware, mirroring pendingOvertimeRequestsCount's structure: gated on ApproveTeam:Leave (or the admin equivalent), counting Leave::where('status', Pending) scoped by supervisor_id the same way LeaveController already scopes its own index. Each count links to its respective queue (leaves index, overtime queue).

## User stories for manual testing (Gherkin)

Scenario: Supervisor sees pending team approvals
  Given I am a supervisor with 2 pending leave requests and 1 pending overtime request from my direct reports
  When I visit the dashboard
  Then I see a 'Pending Approvals' card showing both counts
  And clicking a count takes me to that queue, already scoped to my team

Scenario: Admin sees organization-wide pending approvals
  Given I am an admin and there are pending leave and overtime requests across the organization
  When I visit the dashboard
  Then the counts reflect the whole organization, not just requests I personally supervise

Scenario: User without any approval permission sees no card
  Given I hold neither ApproveTeam:Leave, ApproveTeam:OvertimeAuthorization, nor Manage:OvertimeAuthorization
  When I visit the dashboard
  Then no 'Pending Approvals' card is shown
