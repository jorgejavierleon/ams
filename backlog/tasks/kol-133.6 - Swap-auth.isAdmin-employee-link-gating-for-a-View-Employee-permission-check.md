## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Since KOL-133.4, employees.* routes are gated by View:Employee/Manage:Employee permissions instead of role:admin. The shared Inertia prop auth.isAdmin (HandleInertiaRequests.php) still checks the admin role name, and several list pages (leaves, overtime pacts, overtime rest-day-balances, overtime requests, workdays, documents) use it to decide whether to render a link to an employee's show page. This drifts from actual route access once an org edits the admin role's permissions or grants View:Employee to a different role via the Roles screen: a role stripped of View:Employee would still see a link that 403s, and a role granted View:Employee wouldn't see the link at all.
<!-- SECTION:DESCRIPTION:END -->
