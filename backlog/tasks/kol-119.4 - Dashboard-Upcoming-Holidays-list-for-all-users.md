## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a small list widget, visible to every authenticated user regardless of role, showing the next few upcoming holidays (Holiday model, filtered by the organization's country, ordered by date, limited to e.g. the next 5). No permission gate needed. Empty state when none are configured or all are in the past.

## User stories for manual testing (Gherkin)

Scenario: Upcoming holidays exist
  Given there are holidays on file with dates in the future
  When any user visits the dashboard
  Then they see the next few upcoming holidays listed nearest-first, with name and date

Scenario: No upcoming holidays configured
  Given there are no future holidays on file
  When I visit the dashboard
  Then the widget shows a clear empty state rather than disappearing silently or erroring
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Add a private upcomingHolidays(): array method to DashboardController: Holiday::where('country','cl')->whereDate('date','>=',today())->orderBy('date')->limit(5)->get(), mapped to {id,name,date}. HolidayScope already restricts to official + the current org's own holidays; country filter added explicitly since the app is Chile-only today (mirrors the 'cl' literal in SyncOfficialHolidays). No permission gate — always computed and returned.
2. Pass 'upcomingHolidays' => $this->upcomingHolidays() from DashboardController::index.
3. Add an UpcomingHolidaysCard to resources/js/pages/dashboard.tsx, always rendered (every authenticated user), with an explicit empty-state message when the array is empty.
4. Since every user now gets at least this widget, drop the dead PlaceholderPattern fallback branch from the Dashboard component entirely — closes out the epic's stated goal of no more empty placeholder boxes for supervisors/admins.
5. Add lang keys under ui.dashboard.upcoming_holidays in lang/en/ui.php and lang/es/ui.php.
6. Add tests/Feature/DashboardUpcomingHolidaysTest.php: ordering nearest-first, past holidays excluded, limited to 5, country filter, org + official holidays both included, empty state.
7. pint --dirty, sa test --compact, npm run types:check, live browser check of the populated list and confirm the placeholder is gone for a bare user with nothing else on their dashboard.
